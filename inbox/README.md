# inbox

**临时投递区。这里的所有内容都默认会在 30 天后被删除。**

用法：任何还没想好归到 `design/` 还是 `research/` 的文档，先丢这里，别在脑子里排队。

出栈只有三种方式：

1. 升级 —— 移到 `design/<主题>/` 或 `research/`，按 `YYYY-MM-DD-主题-类型.md` 重命名
2. 归档 —— 移到 `archive/<年份>/`
3. 删除 —— 结论已经写进别处，原件没有保留价值

检查逾期文件：

```bash
cd .. && ./scripts/cleanup-inbox.sh
```

这个目录长期为空是健康状态。如果它开始堆积，说明流程出了问题，不是目录不够大。
